# โฮสต์กลับเข้าห้องและการยุบห้องเมื่อไม่มีคนใช้งาน

## กติกา
- พักจอ สลับแอป เน็ตหลุด รีเฟรช หรือปิดแท็บ ไม่สั่งปิดห้อง
- เครื่องและเบราว์เซอร์เดิมที่ยังเก็บ token จะกลับเข้าห้องเดิมอัตโนมัติ ตราบใดที่ห้องยังไม่หมดอายุ
- การกลับจากพักจอ หน้าเว็บในแคช หรือเครือข่ายกลับมา จะยืนยันสิทธิ์โฮสต์และขอสถานะล่าสุด
- หน้าจอแสดงสถานะกำลังเชื่อมกลับ พร้อมปุ่มลองเชื่อมต่ออีกครั้ง
- คำสั่งเกมสำคัญและแชตโฮสต์ที่กดตอนหลุดจะไม่ถูกเก็บไปส่งย้อนหลังเมื่อเน็ตกลับ
- โฮสต์กดปิดห้องเอง ยุบห้องทันทีตามขั้นตอนปิดเดิม
- มีโฮสต์อย่างน้อยหนึ่งจอ หรือผู้เล่นจริงเชื่อมต่ออยู่ ห้องยังอยู่ แม้ไม่ได้กดปุ่ม
- ทุกคนขาดการเชื่อมต่อครบ 10 นาที ยุบห้องอัตโนมัติ ตรวจทุก 5 วินาที
- บอท ตัวจับเวลาเกม การบันทึกข้อมูล และคนเปิดรายการห้อง ไม่ต่ออายุห้อง

## การนับเวลา
เซิร์ฟเวอร์ตรวจ Socket.IO connection และการเป็นสมาชิกห้องจริง อัปเดตสัญญาณห้องทุกประมาณ 30 วินาที เมื่อได้รับ disconnect ของคนจริง จะให้เวลาฟื้นการเชื่อมต่ออีก 10 นาที การพักจอที่ระบบมือถือหยุดส่งข้อมูลอาจต้องรอ Socket.IO ตรวจพบการหลุดก่อนเริ่มช่วงนี้ (ใช้ ping interval 25 วินาที และ timeout 90 วินาทีตามค่าที่มีอยู่เดิม)

เก็บ lastRoomActivityAt และ roomIdleExpiresAt เป็นเวลาจริงลง snapshot การรีสตาร์ตไม่เริ่มนับใหม่ให้ห้องที่มีข้อมูลเหล่านี้อยู่แล้ว ห้องจากเวอร์ชันเก่าที่ไม่มีข้อมูลนี้จะได้รับช่วงเปลี่ยนผ่าน 10 นาทีหนึ่งครั้งหลังโหลด เมื่อบันทึกแล้วจะใช้เวลาเดิมต่อไป

การกลับมาตั้งแต่เวลาหมดอายุเป็นต้นไป ถ้าไม่มีสมาชิกเชื่อมต่ออยู่ จะไม่เปิดห้องเก่าขึ้นใหม่ การปิดห้องรอ snapshot ที่กำลังเขียนให้จบก่อนลบ และห้ามเขียน snapshot ใหม่ระหว่างปิด

โฮสต์เดิมใช้ token ยืนยันสิทธิ์โดยไม่ต้องพิมพ์รหัสห้องซ้ำ ส่วนการเข้าจากเครื่องอื่นคงใช้รหัสห้องตามระบบเดิม token โฮสต์และรหัสผ่านห้องไม่ถูกส่งไปใน room_update หรือข้อมูลตอบกลับการเข้าห้องของผู้เล่น

## ตรวจสอบ
รันจากโฟลเดอร์โครงการ:

```sh
node --test tests/*.test.js
```

ผ่านการทดสอบอัตโนมัติ 18 กรณี ครอบคลุมเวลาหมดอายุ บอท โฮสต์หลายจอ การกู้คืน deadline การลองเชื่อมต่อซ้ำ timeout คำสั่งตอนออฟไลน์ และการปิดห้องระหว่างบันทึกข้อมูล

ทดสอบกับเซิร์ฟเวอร์ Node.js และ Socket.IO client จริงอีก 10 กรณี: ปิดข้อมูล AWS ในสภาพแวดล้อมทดสอบและจำลองการอ่านสถานะระบบ ทดสอบหลุด/กลับเข้า หลายจอ ผู้เล่นคงห้องไว้ ครบเวลา กลับก่อนครบเวลา ไม่ฟื้นห้องที่หมดอายุ ปิดห้องเอง และไม่เผยข้อมูลยืนยันสิทธิ์โฮสต์

ยังไม่ได้ทดสอบการพักจอบนอุปกรณ์มือถือจริง หรือเชื่อมกับ DynamoDB/Elastic Beanstalk จริง การตรวจหน้าเว็บด้วยเบราว์เซอร์อัตโนมัติยังทำไม่ได้ในสภาพแวดล้อมนี้ จึงไม่อ้างว่าผ่านการทดสอบบนเบราว์เซอร์จริง
