🛠️ ตั้งค่าห้องก่อนสร้าง

ตอนนี้ ยังไม่มีห้องจริง — ยังไม่มีรหัสห้อง ผู้เล่นเข้าไม่ได้ จนกว่าจะกด "✅ สร้างห้อง" ด้านล่าง ตั้งค่าให้เรียบร้อยก่อนได้เลย (แก้ทีหลังได้จากปุ่ม "⚙️ ตั้งค่าห้อง")

🔒รหัสผ่านห้อง (กันแอดมินคนอื่นแย่งคุม)

แอดมิน/จอคนอื่นที่เลือกห้องนี้จากกริด "ห้องที่ยังเปิดอยู่" ต้องใส่รหัสนี้ก่อนถึงจะเข้าคุมได้ ปล่อยว่าง = ไม่ล็อก

🎫รหัสห้อง (ฝั่งผู้เล่นเข้าร่วม)

รหัสที่ผู้เล่นต้องกรอกตอนเข้าร่วม (นอกจากโค้ดห้อง) ปล่อยว่าง = ใครรู้โค้ดห้องก็เข้าได้เลย

👥จำนวนผู้เล่นสูงสุด

ครบแล้วผู้เล่นใหม่จะเข้าไม่ได้ (ไม่นับโฮสต์) ปล่อยว่างหรือใส่ 0 = ไม่จำกัด

☠️ แสดงบทบาทเมื่อผู้เล่นตาย
เปิดอยู่ — เมื่อผู้เล่นตาย คนอื่นจะเห็นอาชีพที่มุมขวาล่างของการ์ดผู้เล่น (เปลี่ยนได้จนกว่าจะเริ่มเกม)

ไม่พบห้องที่ตรงกับคำค้นหา
🔒รหัสผ่านห้อง (กันแอดมินคนอื่นแย่งคุม)

ถ้าตั้งรหัสผ่านไว้ แอดมิน/จอคนอื่นที่กดเลือกห้องนี้จากกริด "ห้องที่ยังเปิดอยู่" จะต้องใส่รหัสผ่านนี้ให้ถูกก่อนถึงจะเข้าคุมห้องได้ (คนละอย่างกับ "รหัสห้อง" ด้านบนที่บอกผู้เล่นไว้เข้าร่วมเกม) ปล่อยว่างไว้ = ไม่ต้องใส่รหัสผ่าน

🎫รหัสห้อง (ฝั่งผู้เล่นเข้าร่วม)

คนละอย่างกับ "รหัสผ่านห้อง" ด้านบน — รหัสนี้บอกให้ผู้เล่นกรอกตอนเข้าร่วมห้อง (นอกเหนือจากโค้ดห้องที่เห็นบนสุด) ปล่อยว่างไว้ = ใครรู้โค้ดห้องก็เข้าร่วมได้เลยไม่ต้องมีรหัสเพิ่ม

👥จำนวนผู้เล่นสูงสุด

เมื่อครบจำนวนนี้แล้ว ผู้เล่นใหม่จะเข้าร่วมห้องนี้ไม่ได้อีก (ไม่นับโฮสต์) ปล่อยว่างหรือใส่ 0 = ไม่จำกัดจำนวน

☠️ แสดงบทบาทเมื่อผู้เล่นตาย
เปิดอยู่ — เมื่อผู้เล่นตาย คนอื่นจะเห็นอาชีพที่มุมขวาล่างของการ์ดผู้เล่น (เปลี่ยนได้จนกว่าจะเริ่มเกม)
📋 การโหวต

⚙️ปรับเงื่อนไขจบเกม

ปิดเงื่อนไขจบเกมข้อใดไว้ได้ — เกมจะไม่จบจากเงื่อนไขนั้นแม้เข้าเงื่อนไขจริง

🗳️นับเวลาโหวต

ปิดได้ทั้งก่อนเปิดโหวตหรือระหว่างเปิดโหวตอยู่ — ปิดไว้แล้วโหวตจะไม่หมดเวลาเอง ต้องกดปิดโหวตเองเท่านั้น

🤖จัดการบอท

เพิ่มบอทมานั่งแทนผู้เล่นจริง เพื่อให้แจกบทได้ครบตามจำนวน — กด "🎭 เข้าสิง" ที่การ์ดผู้เล่นในกริดหลักเพื่อเปิดหน้าจอของบอทตัวนั้นเป็นป๊อปอัปแล้วเล่นแทนได้เหมือนผู้เล่นปกติ

🧠 บอทเล่นเองอัตโนมัติ (ทั้งห้อง)
บอทที่ไม่มีคนเข้าสิงจะเล่นเอง (กัด/โหวต/ใช้สกิล)
