🚦 เปิด / ปิดเซิร์ฟเวอร์ กำลังเช็ค...

ปิด = ทุกคนที่เล่นอยู่จะเห็นหน้าจอ “เซิร์ฟเวอร์กำลังปิด” เต็มจอทันที และเข้าเกมไม่ได้เลยแม้กดรีเฟรช/เปิดเว็บใหม่ จนกว่าจะกดเปิด
• หน้าแอดมินนี้ยังใช้งานได้ตามปกติ (ไว้กดเปิดคืน)
• ปิดทุกห้องปกติที่กำลังเล่น/รออยู่ (ไม่นับแพ้/ชนะ/“ออกเกม” และไม่เข้าประวัติของใครเลย) · ยกเว้น “ห้องผู้ทดสอบ” (ห้อง/บอท/การสิง/ผู้เล่นทดสอบเล่นต่อได้ ไม่ถูกเตะ) · ชื่อ/สถิติเดิมของผู้เล่นไม่ถูกแตะ
• ปิดได้ 2 แบบ: ปิดทันที (เว้นช่องวันที่/เวลาว่างไว้) หรือ เลือกวันที่และเวลาที่จะปิดล่วงหน้า (ผู้เล่นเห็นแถบเตือนนับถอยหลังจนกว่าจะถึงเวลา + ข้อความของคุณ ยกเลิกได้ก่อนถึงเวลา) · ระหว่างรอ ปรับเวลาปิดให้ไวขึ้น/ถอยออกได้ตลอด (ตั้งใหม่ทับของเดิม) · ใส่ข้อความ/วันที่-เวลาที่คาดว่าจะเปิดได้ จะโชว์บนหน้า “กำลังปิด”
• สถานะ “ปิด” และกำหนดการปิดที่ตั้งล่วงหน้ายังไม่ถึงเวลา ถูกจำไว้แม้เซิร์ฟเวอร์รีสตาร์ท/deploy ใหม่
• ตอนเปิด ทุกคน (ผู้เล่น/โฮสต์) จะถูกพากลับ หน้าแรก ให้อัตโนมัติ ไม่กลับเข้าห้องเดิม — ต้องสร้าง/เข้าห้องใหม่

🔄 บังคับทุกคนรีโหลดเว็บ

สั่งให้ทุกเครื่องที่เปิดเกมอยู่โหลดใหม่แล้วกลับ หน้าแรก (ใช้กันเครื่องที่ตกหล่นอัปเดต)
• ⚠️ ปุ่มรีโหลด 3 ปุ่มแรกปิดทุกห้องปกติที่กำลังเล่น/รออยู่ทันที (ไม่นับแพ้/ชนะ/“ออกเกม” ไม่เข้าประวัติใคร) และไม่กลับเข้าห้องเดิม — ต้องสร้าง/เข้าห้องใหม่ · ห้องผู้ทดสอบไม่ถูกปิด/ไม่ถูกพากลับหน้าแรก
• ไม่วนลูป: กลับหน้าแรก 1 ครั้งต่อเครื่อง
• การ deploy ไฟล์ใหม่ไม่เรียกปุ่มเหล่านี้เอง — ผู้เล่นที่กำลังเล่นไม่ถูกรบกวน แค่ตอนกลับหน้า index จะเห็น “มีอัปเดตเกมใหม่” ให้กดเอง · สำหรับ Tester ที่ไม่มี index ให้ใช้การ์ด “🧪 บังคับอัปเดตโหมดผู้ทดสอบ” โดยตรง · ปุ่ม “📣 แจ้งมีรุ่นใหม่” ด้านล่างใช้ประกาศโดยไม่แตะห้องใดเลย (เช่น เปลี่ยนรูปบน S3)
• เครื่องที่อยู่หน้าแรก/แท็บหลับอยู่ จะโหลดตามเองภายใน ~20 วิ หรือตอนกลับมาเปิดแท็บ

🧪 บังคับอัปเดตโหมดผู้ทดสอบ

ส่งคำสั่งอัปเดตตรงไปยังแท็บ Tester ที่กำลังออนไลน์ โดย ไม่ปิดห้องทดลอง และไม่พากลับหน้า Index · แท็บที่หลับ/พลาด event จะตรวจ tester update epoch จากเซิร์ฟเวอร์เองเมื่อกลับมาทำงาน · หลังอัปเดตจะโหลด host/player หน้าเดิม ต่อและใช้ห้อง/บอท/การสิงเดิมต่อ

🧪 เข้าในฐานะผู้ทดสอบ

สำหรับทดสอบหลายบัญชีผู้เล่นบนเครื่องเดียว — แต่ละแท็บนับเป็นคนละผู้เล่น
• เข้าเล่นได้แม้ปิดเซิร์ฟเวอร์อยู่ — ไว้ลองเล่นอัปเดตใหม่ก่อนเปิดจริง (ผู้เล่นทั่วไปยังเข้าไม่ได้เหมือนเดิม) ห้องที่สร้างจากแท็บทดสอบนี้ไม่ถูกปิดโดยปุ่มปิด/เปิดเซิร์ฟเวอร์และปุ่มรีโหลด (โฮสต์/ผู้เล่น/บอท/การเข้าสิงเล่นต่อได้ ไม่ถูกเตะ ไม่ถูกพากลับหน้าแรก) — สิทธิ์นี้ตัดสินจากบัตรผ่านที่ server ออกให้เท่านั้น (บัตรอายุ 12 ชม. และยังใช้ต่อได้ข้ามการรีสตาร์ท/deploy)
• เปิดในแท็บใหม่ หน้าแอดมินนี้ยังอยู่ครบ กดซ้ำเพื่อเปิดอีกแท็บ = อีกบัญชี
• ชื่อของแท็บทดลองตั้งโดยเซิร์ฟเวอร์เองตาม slot ที่ยังว่าง เช่น โฮสต์1 / โฮสต์2 / ผู้เล่น1 / ผู้เล่น2 และไม่ถูกบันทึกเป็นบัญชีจริง

🔢 ชื่อจะถูกตั้งอัตโนมัติโดยเซิร์ฟเวอร์ เช่น โฮสต์1 / โฮสต์2 / ผู้เล่น1 / ผู้เล่น2 และเลขที่ว่างจะถูกนำกลับมาใช้ใหม่

🧹 ล้างข้อมูลเกมทิ้งทั้งหมด

ทำให้ทุกคนกลับเป็นผู้เล่นใหม่ ลงทะเบียนครั้งแรก:
• ลบสถิติแพ้/ชนะ รายชื่อผู้เล่นทั้งหมด และประวัติเข้าเล่นทุกอย่างใน DynamoDB
• ปิดทุกห้องที่เปิดอยู่ตอนนี้ (เกมที่กำลังเล่นอยู่จะจบทันที)
• ล้างชื่อ / token / รหัสโฮสต์ที่จำไว้ในเครื่องของทุกคน (เครื่องที่ออนไลน์ล้างทันที เครื่องที่ออฟไลน์จะล้างตอนเปิดเกมครั้งถัดไป)
ย้อนกลับไม่ได้
